排列有顺序，用 `vis` 标记已选元素；组合无顺序，用 `st` 限制选择范围。`p` 用于记录当前路径。

子集是不定长组合，每次进入 DFS 时记录答案；排列和定长组合在满足长度时记录。

存在重复元素时，先排序再同层去重；排序后还可根据题意剪枝。

### 排列与组合对比

| 类型 | 每层选择范围 | 防止重复选择 | 记录答案 |
| --- | --- | --- | --- |
| 排列 | 从 `0` 开始 | 使用 `vis` | 长度达到 `n` |
| 组合 | 从 `st` 开始 | 只向后选择 | 长度达到 `k` |

排列可以回头选，但不能选择当前路径中用过的元素；组合不回头，只从当前位置之后继续选。

### 去重条件总结

以下去重方式都需要先对数组排序。

| 问题 | 去重条件 |
| --- | --- |
| 重复元素排列 | `i > 0 && nums[i] == nums[i - 1] && !vis[i - 1]` |
| 重复元素组合或子集 | `i > st && nums[i] == nums[i - 1]` |

### [46. 全排列 - 力扣（LeetCode）](https://leetcode.cn/problems/permutations/description/)

给定一个不含重复数字的数组，返回其所有可能的全排列。

```cpp
class Solution {
public:
    vector<vector<int>> permute(vector<int>& nums) {
        int n = nums.size();
        vector<int> vis(n), p(n);
        vector<vector<int>> ans;
        auto dfs = [&](auto &&self, int stp) -> void {
            if(stp == n) {
                ans.push_back(p);
                return ;
            }
            for(int i = 0; i < n; ++i) {
                if(vis[i]) continue;
                vis[i] = 1;
                p[stp] = nums[i];
                self(self, stp + 1);
                vis[i] = 0;
            }
        };
        dfs(dfs, 0);
        return ans;
    }
};
```

### [39. 组合总和 - 力扣（LeetCode）](https://leetcode.cn/problems/combination-sum/description/)

从无重复的候选数字中选取若干个数，使其和等于目标值；每个数字可以重复选取。

```cpp
class Solution {
public:
    vector<vector<int>> combinationSum(vector<int>& candidates, int target) {
        int n = candidates.size();
        vector<vector<int>> ans;
        vector<int> p;
        sort(candidates.begin(), candidates.end());
        int sum = 0;
        auto dfs = [&](auto &&self, int st) -> void {
            if(sum == target) {
                ans.push_back(p);
                return ;
            }
            for(int i = st; i < n; ++i) {
                if(sum + candidates[i] > target) break;
                p.push_back(candidates[i]); sum += candidates[i];
                self(self, i);
                p.pop_back(); sum -= candidates[i];
            }
        };
        dfs(dfs, 0);
        return ans;
    }
};
```
