# 刷题模版



> Windows 用wsl2，等价于linux开发体验。
>
> macos需要安装gcc `brew install gcc`，需要**记住版本**，例如`g++-15`。cph、c/c++、shell脚本需要设置正确版本。



在刷题目录下的`.vscode/settings.json`里面禁止ai自动补全：

```json
    // 关闭 ai自动补全！！！
    "editor.inlineSuggest.enabled": false,
    "ai.completions.enabled": false,
    "editor.suggest.showInlineCompletions": false
```
